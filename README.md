### Quickstart

```bash
git clone https://github.com/LILSYNNOFFICIAL/RuRu-AI.git
cd RuRu-AI
bun install
bun run dev          # Launch the luxurious studio
```

CLI Example:
```bash
bunx ruru render examples/cinematic.tsx --dry-run --model=kling-v3-pro
```
